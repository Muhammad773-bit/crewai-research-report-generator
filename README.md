# Crewai Research Report Generator

Multi-agent system built with CrewAI: researcher and writer agents work together to produce a structured research report on any topic.

**Tech:** Python, CrewAI, LLM agents

## Run it

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python automated_research_report_generator/main.py
```

API keys are read from environment variables. Copy `.env.example` to `.env` and fill in your own keys.
